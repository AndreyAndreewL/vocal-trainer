# Тренажёр вокала (MVP)

Локальный веб-питч-тренажёр: микрофон → высота ноты в реальном времени → четыре упражнения со счётом
(удержание, гамма, интервалы, унисон с зацикленным эталоном).  
Без сервера-бэкенда, без ключей, без сети и аккаунтов. Всё в папке `vocal-trainer`.

## Почему нельзя просто открыть `index.html`

Микрофон в браузере работает только в **secure context**:

- `http://localhost…` или `http://127.0.0.1…`
- либо `https://…` (в том числе с самоподписанным сертификатом)

Открытие файла как `file://…` микрофон **не даст**. Поэтому нужен крошечный лаунчер `serve.py`.

## Запуск на ПК

Нужны Python 3 и современный браузер (Chrome / Edge / Firefox).

```bash
cd vocal-trainer
python serve.py
```

Откройте в браузере: **http://localhost:8099/**

1. Нажмите «Включить микрофон» и разрешите доступ.
2. Выберите упражнение → «Начать упражнение».
3. Кнопка «Эталон» проигрывает целевую ноту мягким тоном.

Порт по умолчанию — `8099`. Другой порт:

```bash
python serve.py --port 8100
```

## Запуск на телефоне (та же Wi‑Fi сеть)

На ПК:

```bash
python serve.py --https
```

В консоли появятся адреса вида `https://192.168.x.x:8099/`.  
Откройте этот адрес в браузере телефона.

Браузер покажет предупреждение о сертификате — для локального самоподписанного HTTPS это ожидаемо.  
Примите исключение / «Продолжить», иначе микрофон не заработает.

Для HTTPS нужен `openssl` в PATH (часто уже есть с Git for Windows).

## Упражнения

| Упражнение        | Что делать                                      | Счёт                          |
|-------------------|--------------------------------------------------|-------------------------------|
| Удержание ноты    | Держать одну ноту ~8 с                           | Доля времени в ±25¢ + стабильность |
| Гамма до-мажор    | Вверх и вниз по ступеням                         | Средний % по нотам            |
| Интервалы         | Слушаете две ноты → поёте вторую                 | Доля времени в зоне цели      |
| Унисон            | Петь вместе с зацикленным эталоном (~20 с)       | Доля «в цели» + ср. отклонение + тренд |

Порог «попал» — **±25 центов** (учебный тренажёр, не студийный тюнер).

### Режим «Унисон»

Эталон играет **петлёй без пауз** (дрон / гамма / ступени 1–3–5 / сирена), параллельно идёт анализ голоса:

- индикатор **выше / ниже / в цель** и дорожка подстройки;
- подсказка, **что произносить** (а-а-а, о-о-о, ми–мэ–ма, …);
- настройки: нота дрона, темп петли, громкость эталона.

**Важно:** наденьте наушники (можно один). Иначе микрофон слышит динамики, и детектор может принять эталон за ваш голос.  
В режиме есть **гейт по уровню**: тишина и тихая утечка эталона **не** считаются попаданием.

Прогресс по дням хранится в `localStorage` браузера (без регистрации).

Опционально: галочка «Метроном» (~100 BPM).

## Проверка детектора (без микрофона)

```bash
node test_pitch.js
```

Синтетические синусы (440 Гц и набор нот): ошибка частоты должна быть **≤ 1%**.  
При успехе процесс завершается с кодом `0`.

## Файлы

- `index.html` — приложение (UI + упражнения)
- `pitch.js` — YIN-детектор и перевод Гц → нота/центы
- `serve.py` — локальный HTTP/HTTPS-лаунчер
- `test_pitch.js` — автотест точности
- `ТЗ_ВЕБ_ТРЕНАЖЁР_ВОКАЛА.md` / `БРИФ.md` — постановка

## Ограничения MVP

- Только интонация/высота, без «красоты голоса» и распознавания слов.
- Точность зависит от микрофона, шума и браузера; цель — тренировка слуха и попадания в ноту.
